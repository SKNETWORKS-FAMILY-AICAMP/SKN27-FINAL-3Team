# SKN27-FINAL-3Team

교통분쟁 AI 서비스 프로젝트 저장소다. 기존 루트 폴더를 유지하면서 화면, AI, 데이터 파이프라인, 저장소, 테스트, 문서를 책임별로 분리한다.

## 루트 폴더 역할

| 폴더 | 역할 |
|---|---|
| `app/` | 사용자 화면, API entrypoint, application service를 관리한다. |
| `ai/` | Supervisor, Agent, 공통 AI 결과 schema, 모델 검증 보조 코드를 관리한다. |
| `etl/` | 법률, 과태료 룰, 판례/사례, 영상 manifest 등 데이터 수집과 전처리를 관리한다. |
| `storage/` | DB, migration, RAG metadata, 개발용 저장소 실행 환경을 관리한다. |
| `test/` | 단위, 통합, E2E, 수동 시나리오, fixture 검증 자산을 관리한다. |
| `docs/` | 구현 기준 문서, API 초안, 이슈별 상세 기준, 리스크 문서를 관리한다. |

## 배치 원칙

- 신규 기능은 위 폴더 중 책임이 맞는 위치에 둔다.
- 생성물과 임시 작업물은 소스 코드와 섞지 않는다.
- 원본 개인정보, 원본 고지서, 원본 영상 파일은 저장소에 직접 커밋하지 않는다.
- 최종 자연어 답변은 개별 Agent가 아니라 `ai/supervisor/` 흐름에서 통합한다.
