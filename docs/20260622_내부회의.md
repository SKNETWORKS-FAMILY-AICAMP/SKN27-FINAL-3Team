- 완료 기준:
- 남은 리스크 또는 검증 필요 항목:

- 문서나 회의에서 확정되지 않은 모델, API, schema는 `검증 필요`로 적는다.
- 구현이 끝난 것처럼 쓰지 않는다. 현재 완료된 것과 설계가 필요한 것을 분리한다.

## 7. 필주 `workzion2`

### 7.1 오늘 회의에서 확인된 상태

- 고지서 OCR에서 외부로 넘길 핵심은 schema output이다. 이슈 내 설명이 많더라도 `OCRResult`, `structured_result`, `missing_documents`, `objection_possible`, `limitations`처럼 후속 노드가 실제로 읽는 필드만 우선 검토한다.
- 서류 단계 구분은 `사전통지서`, `1차`, `2차`, `독촉장`을 별도 유형으로 분리하지 않는다.
- 정규화 기준은 `사전통지서 = 1차`, `사전통지서 독촉 = 2차 통지서`다.
