# 교통 과태료 이의신청 절차 — 종합 정리

> 근거 법령: 질서위반행위규제법(이하 "질서법"), 도로교통법, 도로교통법 시행령·시행규칙
> 본 문서는 일반적 절차 안내이며 법률 자문을 대체하지 않음. 구체적 사건은 변호사 상담 권장.

---

## 1. 기본 개념

### 1.1 과태료 vs 범칙금

| 구분 | 과태료 | 범칙금 |
|---|---|---|
| 부과 대상 | 차량 소유자 (운전자 불특정) | 운전자 본인 (특정됨) |
| 적발 방식 | 무인단속카메라 등 | 경찰관 현장 적발 |
| 벌점 | 없음 | 있음 (위반 항목에 따라) |
| 보험료 할증 | 원칙적으로 영향 없음 | 벌점이 있으면 영향 가능 |
| 법적 성격 | 행정질서벌 (형벌 아님) | 통고처분 (형사절차 성격) |
| 전과 여부 | 없음 | 없음 (양쪽 다 형벌 아님) |
| 금액 | 통상 범칙금보다 소폭 높음 (~1만원 차이) | 통상 과태료보다 소폭 낮음 |
| 재전환 | 범칙금 → 과태료 전환 불가 | — |

### 1.2 핵심 원칙
- 운전자를 특정할 수 있으면 범칙금, 특정할 수 없으면 과태료.
- 과태료 → 범칙금 전환은 가능하나 역방향(범칙금 → 과태료)은 불가능.
- 벌점은 운전자 개인에게 귀속되며, 소유자(운전자 아닌 경우)에게는 벌점이 가지 않음.

## 2. 전체 절차 흐름도

```
무인단속 적발
     │
사전통지서 발송 (의견진술 기한 10일 이상 명시, 질서법 §16)
     │
     ├─(A) 기한 내 실제 운전자 특정·인정
     │        → 그 운전자에게 범칙금 통고처분 (벌점 O, 도로교통법 §163)
     │        → 과태료 절차 종료 (완전 전환)
     │
     └─(B) 특정 안 됨 / 무응답
              │
        정식 과태료 부과처분 (행정청)
              │
              ├─(B-1) 1차 과태료 부과 단계에서도 여전히 전환 가능
              │        (이파인 '범칙금전환' 메뉴 또는 관할 경찰서 방문)
              │        → 완전 전환, 단 되돌릴 수 없음
              │
              └─(B-2) 60일 이내 서면 이의제기 (질서법 §20①)
                       │
                 ★ 이의제기 즉시 과태료 부과처분 효력 상실 (§20②)
                       │
                 행정청, 이의제기 받은 날부터 14일 이내
                 관할 법원에 통보 (의견·증빙서류 첨부) (§21①)
                 예외: 이의제기 철회 시, 또는 이의제기가 타당하여
                       과태료 부과 불필요 인정 시 → 통보 생략
                       │
                 ★ 이 시점부터는 범칙금 "완전 전환" 불가
                   (다만 §20① 이의제기 결과 운전자가 밝혀지고
                    그 운전자가 별도로 §156/§163에 따라 처벌된 경우
                    → 시행령 §2의2에 따라 과태료 최대 50% 감경 가능)
                       │
                 ★ 통보 시점이 법원 관할 판단 기준 (§26)
                       │
                 법원, 비송사건절차법 준용하여
                 「과태료 재판」 개시 (§28)
                 (상당하다고 인정되면 심문 없이 약식재판 가능, §44)
                       │
                 법원 결정: 부과 / 감액 / 불처벌
                       │
                 결정에 불복 시 → 즉시항고 (§38, 1주일 이내)
                 (약식재판인 경우 고지 후 7일 이내 이의신청, §45)
```

## 3. 범칙금 전환 메커니즘 (핵심 쟁점)

### 3.1 전환이 가능한 시점 — 시간 제한 있음

| 시점 | 전환 가능 여부 | 방법 |
|---|---|---|
| 사전통지 기간 (정식 부과 전) | 가능 | 의견진술서에 운전자 특정·인정 기재 |
| 1차 과태료 부과 직후 (법원행 이전) | 가능 | 이파인(efine.go.kr) '범칙금전환' 메뉴, 또는 과태료 고지서+신분증 지참 후 관할 경찰서 교통민원실 방문 |
| 정식 이의제기(§20) → 법원 통보 이후 | 불가 (완전 전환 창구 닫힘) | 이후엔 §2의2 감경(최대 50%)만 가능 |

- 전환은 **일방향**: 한번 범칙금으로 전환하면 다시 과태료로 되돌릴 수 없음.

### 3.2 본인이 운전자인 경우 vs 타인이 운전자인 경우

**본인이 실제 운전자였던 경우**
- 사전통지~1차 과태료 부과 단계에서 스스로 인정 시 → 완전 전환 가능 (위 3.1 표 참조)
- 정식 이의제기 이후 단계에서 스스로 밝히는 경우 → 조문상 §2의2 감경 대상에서 명시적으로 배제되어 있지 않으나, 행정청 재량("할 수 있다") 사항이라 자동 적용은 아님

**타인이 실제 운전자로 밝혀진 경우 (정식 이의제기 §20① 단계)**
- 완전 전환이 아니라 **과태료 최대 50% 감경** (질서법 시행령 §2의2①)
- 요건: 그 운전자가 도로교통법 §156에 따라 처벌(§163 범칙금 통고처분 포함)된 경우
- 구조: 소유자의 과태료는 유지(감경)되고, 별도로 실제 운전자에게 범칙금·벌점 부과
- 체납 중인 당사자에게는 이 감경이 적용되지 않음 (시행령 §2의2①但)
- 동일 조항상 다른 감경사유(기초생활수급자 등)와 원칙적으로 중복 감경 불가 (자진납부 감경은 예외적으로 중복 가능)

## 4. 이의제기 시 신원 노출 여부 판단

### 4.1 신원이 노출되지 않으면서 다툴 수 있는 사유 (권장)
운전자가 누구인지와 무관하게 과태료 처분 자체의 위법·부당성을 다투는 사유:
- 속도측정기 오차·검교정 유효기간 경과 등 측정 신뢰성 문제
- 제한속도 표지판·노면표시의 규격 미달, 시인성 문제(가려짐 등)
- 차량번호 오인식
- 도로교통법 시행규칙 §142상 부득이한 사유: 범죄예방/긴급사건, 도로공사·교통지도단속, 응급환자 수송, 화재·수해 등 구난작업, 장애인 승하차 지원, 고장·도난차량 등
- 과태료 금액 산정 오류, 재량권 일탈·남용

→ 이 경우 소유자 책임 성립 자체를 다투는 것이므로 **운전자 특정 없이도 이의신청/감액·취소 가능**

### 4.2 신원이 노출되는 사유 (범칙금 전환 리스크)
- "제가 운전했습니다" (본인 인정)
- "OOO가 운전했습니다" (타인 지목)

### 4.3 벌점 있는 항목에서의 전략 요약

| 상황 | 권장 전략 |
|---|---|
| 다툴 사유 없음, 위반 사실 인정 | 아무 의견 제출 없이 조용히 과태료만 납부 (벌점·범칙금 리스크 원천 차단) |
| 표지판 하자·측정 오류 등 실질적 다툴 사유 있음 | 운전자를 밝히지 않는 선에서 의견진술/이의제기 (감액·취소 노리면서 벌점 리스크 회피) |
| 본인이 운전자였음을 밝히고 싶은 경우 | 벌점 없는 항목이면 무방, 벌점 있는 항목이면 신중히 판단 (금액 차이 vs 벌점·보험료 리스크) |

## 5. 법원 이의제기 → 비송사건 재판

### 5.1 절차 (질서법 §20~§28)
1. 당사자, 과태료 부과 통지 받은 날부터 **60일 이내** 서면 이의제기 (§20①)
2. 이의제기 즉시 원처분 효력 상실 (§20②)
3. 법원 통보 전까지 서면으로 이의제기 철회 가능 (§20③)
4. 행정청, 이의제기 받은 날부터 **14일 이내** 관할 법원에 통보, 의견·증빙서류 첨부 (§21①)
   - 예외: 이의제기 철회 시 / 이의제기가 타당하여 과태료 불필요 인정 시 → 통보 생략, 행정청이 직접 불처분
5. 법원 관할은 통보 시점 기준으로 확정 (§26)
6. 관할 없다고 판단 시 법원이 직권 이송 결정, 이송결정에도 즉시항고 가능 (§27)
7. 법원, 비송사건절차법 준용하여 결정으로 과태료 재판 (§28)
   - 원칙: 심문기일 열어 당사자 진술 청취
   - 예외: 상당하다고 인정 시 심문 없이 약식재판 가능 (§44)
   - 약식재판 불복: 고지 후 7일 이내 이의신청 (§45), 적법하면 약식재판 효력 상실 후 정식재판 진행
8. 법원 결정: 부과 / 감액 / 불처벌

### 5.2 성격
- 비송사건절차법 준용 (형사소송 아님)
- 검사 기소 절차 없음, 전과 남지 않음
- 법원 재량 넓음 (정식 소송만큼 판례 구속력 강하지 않음)

### 5.3 관할 법원
- 원칙: 당사자 주소지 관할 지방법원 또는 그 지원 (§25)

## 6. 즉시항고 (법원 결정 불복)

### 6.1 근거 및 효력
- 질서법 §38①: 당사자와 검사는 과태료 재판에 대해 즉시항고 가능, **항고는 집행정지 효력 있음** (별도 신청 불요, 자동 발생)
- 절차는 질서법 §40에 따라 **민사소송법의 항고 규정을 준용**

### 6.2 기한
- 결정 **고지받은 날부터 1주일(7일) 이내**

### 6.3 방법
- **항고장**을 **원심법원**(과태료 재판을 한 지방법원)에 제출 (항고법원에 직접 제출 아님)
- 항고장 필수 기재사항: 당사자·법정대리인, 항고 대상 결정의 표시, 항고 취지
- 항고이유(사실관계, 증거, 유사 판례 등)를 구체적으로 기재 필요

### 6.4 이후 절차
- 원심법원의 흠결 보정명령 가능 → 보정 시 1주 이내 항고기록을 항고법원에 송부
- 항고법원 결정에는 이유 기재 필수 (§39)
- 항고심 절차는 항소심 절차에 준함, 심리는 항고인이 다투는 범위 내로 한정

### 6.5 비용
- 과태료 부과로 결론 시: 당사자 부담
- 항고 인용(당사자 주장 인정) 시: 항고비용 + 전심 비용 모두 **국고 부담** (§41②)

### 6.6 체크리스트
- [ ] 고지받은 날짜 정확히 기록 (7일 기산점)
- [ ] 원심법원에 항고장 제출
- [ ] 당사자·결정 표시·항고 취지 명확히 기재
- [ ] 구체적 항고이유(사실관계, 증거, 유사 판례) 첨부
- [ ] 집행정지는 자동 발생 (별도 신청 불필요)

## 7. 벌점 기준표 (도로교통법 시행규칙 별표28)

| 벌점 | 대표 위반 항목 |
|---|---|
| 15점 | 신호위반, 시속 20km 초과~40km 이하 속도위반, 어린이보호구역 내 속도위반, 앞지르기 금지구역 위반, 적재제한 위반, 운전 중 휴대전화 사용 |
| 30점 | 중앙선침범, 시속 40km 초과~60km 이하 속도위반, 철길건널목 통행방법 위반, 통학버스 보호의무 위반, 갓길·버스전용차로 무단통행, 경찰의 면허증 제시요구 거부, 어린이보호구역 내 신호위반 |
| 60점 | 시속 60km 초과~80km 이하 속도위반 |
| 80점 | 시속 80km 초과~100km 이하 속도위반 |
| 100점 | 혈중알코올농도 0.03%~0.08% 미만 상태 운전, 보복운전 형사입건, 100km/h 이상 초과 속도위반 |

### 7.1 보호구역 가중
- 어린이·노인·장애인 보호구역, 오전 8시~오후 8시 사이 위반 시 벌점·범칙금·과태료 모두 **2~3배 가중**
- 예: 일반도로 40km/h 초과(30점) → 어린이보호구역 내 동일 위반 시 60점 (즉시 정지처분 대상)

### 7.2 면허 정지·취소 기준
- 40점 이상: 면허정지 (벌점 1점당 1일)
- 누산점수 1년 121점 이상 / 2년 201점 이상 / 3년 271점 이상: 면허취소

## 8. 보험료 영향

| 케이스 | 할증 여부 |
|---|---|
| 과태료 납부 (벌점 없음) | 원칙적으로 영향 없음 |
| 범칙금 + 벌점 있음 | 교통법규위반 경력요율 적용, 최대 20~30%대 할증 가능 |
| 범칙금 + 벌점 0 (예: 20km/h 이내 속도위반) | 원칙적으로 할증 대상 아님이 다수설이나 보험사마다 기준 상이 가능 |

- 근거: 교통법규위반 경력요율은 벌점 부과 대상에게만 적용되는 구조. 위반한 운전자 본인 명의로 자동차보험 가입(기명피보험자) 시 적용.
- 평가주기: 보험가입 시점 기준 전전년 5월 1일~당해연도 4월 30일(2년간)
- 이의제기로 운전자가 특정되는 순간부터 벌점 부과 가능성 발생 → 확실히 잘못이 없다는 확신이 있을 때만 이의제기 권장

## 9. 판례 활용 지점 (교통 과태료 한정)

| 쟁점 | 활용 방향 |
|---|---|
| 측정기 신뢰성 | 속도측정기 오차범위, 검·교정 유효기간, 측정방식 다툼 |
| 표지판·노면표시 하자 | 규격 미달·시인성 문제로 단속 자체의 위법성 다툼 |
| 실운전자 항변 | 소유자가 운전 사실을 부인하는 경우의 인정 기준 |
| 긴급피난·부득이한 사유 | 응급상황 등 정당화 사유 인정 사례 |
| 재량 감경 | 위반 경위·전력 등을 고려한 법원의 감액 사례 |

- 과태료 재판은 비송사건이라 법원 재량이 넓고 정식 소송만큼 판례 구속력이 강하지 않음 → 유사 사실관계 사례를 설득력 보강 자료로 활용
- 검색처: 대법원 종합법률정보, 국가법령정보센터, 케이스노트(casenote.kr)

## 10. 실무 체크리스트 (전체)

- [ ] 사전통지서 수령 즉시 의견진술 기한 확인
- [ ] 억울한 사정이 있다면 블랙박스·사진 등 객관적 증거 확보
- [ ] 다툴 사유가 없다면 의견 제출 없이 조용히 과태료 납부 고려
- [ ] 다툴 사유가 있다면 운전자 특정 없이 사유만 제시하는 방식으로 의견진술/이의제기
- [ ] 실운전자 특정 여부는 벌점·보험료 영향까지 고려해 신중히 결정
- [ ] 정식 과태료 부과 후 다툴 경우 60일 이내 서면 이의제기 (기한 엄수)
- [ ] 법원 재판 단계에서는 유사 사실관계의 판례·결정례 조사해 첨부자료로 활용
- [ ] 법원 결정에 불복 시 고지일로부터 7일 이내 즉시항고, 원심법원에 항고장 제출
- [ ] 벌점 있는 항목은 범칙금 전환 전 벌점·보험료·면허 영향 재확인
