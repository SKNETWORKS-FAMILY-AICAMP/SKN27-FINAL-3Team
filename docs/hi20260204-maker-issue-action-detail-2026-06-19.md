| 구분 | 상세 내용 |
|---|---|
| 입력 조건 | 고지서 OCR 분석 결과, 법률 근거 검색 결과, 사용자 사실관계, 추가 설명, 첨부 증거를 정의한다. |
| 생성 조건 | 필수 입력이 부족하면 초안을 바로 만들지 않고 추가 질문을 요청한다. |
| 문서 구조 | 수신 기관, 제목, 사건 정보, 위반 정보, 사실관계, 이의신청 취지, 근거, 첨부 증거, 주의 문구를 포함한다. |
| 면책/주의 문구 | 법률 자문 아님, 제출 성공 보장 아님, 사용자가 사실관계를 최종 확인해야 함을 포함한다. |
| 출력 형태 | 복사, 다운로드, 리포트 저장에 필요한 구조를 정리한다. |

선행 의존성:

| 선행 이슈 | 필요한 이유 |
|---|---|
| `#23` | 고지서 OCR 필드가 있어야 사건 정보 작성 가능 |
| `#25` | 처분 단계, 부족 서류, 필요 증거가 있어야 초안 근거 작성 가능 |
| `#26` | 법률 근거가 있어야 이의신청 사유 근거 작성 가능 |
| `#22` | 이의신청서 생성 노드도 공통 Agent 결과 schema를 따라야 함 |

이의신청서 생성 노드 input 초안:

```json
{
  "notice_analysis_result": {},
  "law_ground_result": {},
  "user_facts": {},
  "additional_explanation": "",
  "attachments": []
}
```

이의신청서 생성 노드 `structured_result` 초안:

```json
{
  "recipient_agency": "",
  "document_title": "",
  "case_summary": "",
  "violation_summary": "",
  "objection_purpose": "",
  "grounds": [],
  "attachment_list": [],
  "disclaimer": ""
}
```

이슈 comment에 남길 핵심 문장:

```markdown
### 2026-06-19 회의 피드백 반영
```
