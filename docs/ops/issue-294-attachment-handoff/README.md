# #294 채팅 첨부자료 Agent Handoff 기록

## 확정된 흐름과 결론

```text
이미지·PDF
  → 업로드/스캔 완료
  → OCR·문서 분류 (서버 보호 metadata)
  → 사용자가 분류 결과 확인
      ├─ 고지서: 기존 고지서 OCR 확인 → 법령 검색·이의신청 흐름
      ├─ 사고 증거: 기존 사고 사실 확인 → Case Workspace → text_ml·법령 검색
      └─ 불명: downstream 호출 없이 수정·재업로드 안내

동영상
  → 기존 Vision adapter
  → text_ml·법령 검색
  → adapter 미연결·실패 시 실제 분석 결과로 표시하지 않고 안전한 실패 안내
```

- 분류 결과는 클라이언트가 신뢰하지 않는다. 서버가 `attachment_id`로 보호된 metadata를 다시 확인해 handoff한다.
- 원문, OCR 전문, 개인정보, 비밀값은 실행 metadata 및 구조화 로그에 남기지 않는다.
- 영상 품질 고도화와 법령·판례 자동 적재는 #294의 범위 밖이다.
