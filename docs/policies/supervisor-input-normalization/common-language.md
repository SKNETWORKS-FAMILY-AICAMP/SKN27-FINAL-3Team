# 공통 언어 규칙

| 입력 분류 | 의미 | 처리 원칙 |
|---|---|---|
| entity | 도로·문서·기관 같은 대상 | 정책 allowlist 값만 사용 |
| action | 직진·좌회전·이의신청 같은 행동 | 주체가 불명확하면 확인 |
| state | 신호·문서 단계 같은 상태 | 법적 단계가 달라질 수 있으면 재질문 |
| modifier | 정도·방향·위치 수식 | 대상과 같은 절에서만 적용 |
| negation | 않음·아님·못함 | 자동 확정 금지 |
| uncertainty | 같음·아마·모름 | 사용자 확인 또는 재질문 |

조사와 어미는 비교를 위해서만 분리하며 사용자 원문은 바꾸지 않는다.
