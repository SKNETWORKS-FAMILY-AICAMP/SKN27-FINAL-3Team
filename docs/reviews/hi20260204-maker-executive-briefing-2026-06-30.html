9. 남은 일과 의사결정 포인트

프론트 Google 로그인 Next

백엔드 Google auth boundary는 완료됐다. 이제 실제 화면에서 Google Identity Services 버튼, credential callback, token 저장, /auth/me bootstrap을 연결해야 한다.

  • 관련 이슈: #103
  • 완료 기준: 로그인 후 authenticated subject와 user_id가 화면/요청에 반영

실제 저장소 전환 Ops

현재 object storage는 adapter envelope까지 연결됐다. 실제 S3/MinIO binary write/read와 signed URL 발급은 다음 단계다.

  • 결정 필요: S3 우선인지 MinIO 개발환경을 병행할지
  • 연계: 리포트 다운로드, 파일 업로드, 보관/삭제 정책

비동기 실행 연결 Scale

진행률 cache는 준비됐지만, 실제 Agent worker/queue가 progress update hook을 호출하도록 연결해야 한다.

  • 결정 필요: Celery/RQ/내부 worker 중 어떤 실행 모델을 쓸지
  • 연계: analysis_job_progress, agent_invocations, retry/error metric

인증 운영화 Security

Google ID token 검증 경로는 준비됐지만, refresh/logout/token rotation, secret rotation, guest-to-user merge confirmation이 남아 있다.

  • 결정 필요: access token TTL, refresh 정책, 로그아웃 시 서버 상태 관리 여부
  • 연계: 개인정보/상담 이력 계정 귀속 정책

운영 지표 Management

quota와 usage event는 저장되지만, 운영 대시보드나 alert 기준은 아직 별도 구현이 필요하다.

  • 결정 필요: 무료/유료 plan 제한값, 비용 상한, 사용량 리포팅 단위
  • 연계: subscriptions, code_items, usage_quotas, usage_events

통합 QA Launch

각 Agent 구현이 실제로 들어오면 output schema와 Supervisor 병합 결과가 DB 저장/리포트까지 깨지지 않는지 end-to-end로 검증해야 한다.

  • 대상: fine OCR, law RAG, fault ratio, vision, objection report
  • 연계: #40 통합 시나리오, #42 발표/리스크 체크리스트
