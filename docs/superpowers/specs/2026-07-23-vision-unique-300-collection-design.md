# Vision 카테고리별 고유 300건 수집·전처리 설계

## 목표

기존 카테고리별 100건을 포함해 `car_vs_car`, `car_vs_pedestrian`,
`car_vs_motorcycle`, `car_vs_bicycle` 각각 읽을 수 있는 고유 영상 300건을
확보한다. 고유 300건이 확정된 뒤 기존 100건 benchmark와 동일한 32프레임
전처리를 수행한다.

## 작업 경계

- 현재 실행 중인 Qwen/LLaVA GPU 분석과 모델 캐시·출력은 변경하지 않는다.
- 별도 staging 디렉터리에서 다운로드와 CPU 기반 검사를 수행한다.
- 이번 작업에는 VLM 추론, VideoMAE 학습, 새로운 split 확정이 포함되지 않는다.
- 전처리 완료 데이터는 검수 후 후속 학습용 manifest로만 승격한다.

## 고유성 판정

후보는 다음 순서로 제외한다.

1. 동일 Drive ID, `asset_id`, 원본 경로 또는 파일명
2. SHA-256이 동일한 파일
3. 영상 메타데이터와 여러 시점 프레임의 perceptual hash가 사실상 동일한 재인코딩본
4. 동일 `incident_id`로 판정되는 동일 사고의 유사 클립
5. 열리지 않거나 디코딩에 실패한 영상

카테고리별 유효 고유 영상이 300건보다 적으면 후보를 추가 다운로드하고 같은 검사를
반복한다. 정확히 300건이 검증되기 전에는 완료로 표시하지 않는다.

## 전처리

고유 영상별로 기존 benchmark와 동일하게 전체 구간에서 균등하게 32프레임을
선택하고, 기존 resize·색상 변환·저장 규칙을 재사용한다. 전처리 결과는 원본 영상과
분리해 저장하며, 성공 여부·프레임 수·오류를 manifest에 기록한다.

## 완료 조건

- 카테고리별 원본 영상 300건, 전체 1,200건
- 카테고리별 중복 0건 및 손상 영상 0건
- 모든 영상에 고유 `incident_id` 판정 상태 기록
- 각 영상의 32프레임 전처리 성공 또는 명시적인 실패 사유 기록
- 실패분을 대체해 최종 전처리 성공 건수도 카테고리별 300건 유지
- 수집·중복·전처리 요약 보고서 생성

## 검증

최종 manifest를 다시 읽어 카테고리별 개수, 경로 존재, 미디어 가독성,
SHA-256 중복, 근접 중복, `incident_id` 중복, 전처리 프레임 32개를 독립 집계한다.
어느 하나라도 실패하면 완료 처리하지 않는다.
