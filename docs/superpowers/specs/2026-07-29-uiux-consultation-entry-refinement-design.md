# UI/UX 상담 진입 및 유형별 입력 개선 설계

## 목표

기존 로그인·상담·첨부·전송 API 연결을 유지하면서 상담 진입 오류와 시각적 문제를 수정하고, 사용자가 먼저 상담 유형을 고른 뒤 필요한 정보만 입력하도록 흐름을 단순화한다.

## 변경 범위

- 로그인 후 상단 `AI 상담` 버튼이 기존 상담 화면으로 이동하도록 동일한 화면 전환 함수를 사용한다.
- 메인 및 사고 가이드의 주요 버튼에서 주황색 그림자 효과를 제거한다.
- 사고 가이드 하단의 중복 버튼은 `AI 상담 시작` 하나만 유지한다.
- 사용자 채팅 말풍선 본문 글자는 검정색으로 표시한다.
- 상담 입력은 `과태료`와 `과실비율` 선택을 첫 단계로 둔다.

## 유형별 입력

### 과태료

유형 선택 후 다음 항목을 표시한다.

- 고지서 또는 관련 자료 첨부
- 위반 일시
- 위반 장소
- 위반 유형
- 사용자의 질문

### 과실비율

유형 선택 후 기존 상세 사고 항목을 표시한다.

- 사고 유형
- 도로 형태
- 양쪽 차량의 진행 방향과 행동
- 신호·우선권
- 충돌 부위
- 확인된 사실
- 사용자 주장·상대방 주장
