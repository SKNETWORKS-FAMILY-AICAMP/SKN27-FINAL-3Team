# OCR·RAG 발표 슬라이드 v2 디자인

## 목적

발표 청중이 교통사고사실확인원 한 장이 OCR을 거쳐 구조화되고, 그 결과가 RAG 검색 근거로 사용되는 과정을 한눈에 이해하도록 한다.

## 확정 레이아웃

- 16:9 단일 슬라이드, 따뜻한 아이보리 배경
- 상단: 결론형 제목과 개인정보 마스킹 원칙
- 왼쪽: 실제 교통사고사실확인원 이미지와 사고 필드 주석
- 중앙: 편집 가능한 7행 OCR 구조화 결과 표
- 오른쪽: 편집 가능한 RAG 검색 입력·검색 결과 영역
- 하단: “OCR은 과실을 판단하지 않고 확인된 사고 사실만 다음 Agent로 전달한다”는 결론

## 시각 체계

- 네이비: 제목, OCR 영역, 본문 강조
- 오렌지: 원본 필드 주석, 연결선, 핵심 문장
- 틸: RAG 영역
- 모든 표, 텍스트, 도형, 연결선은 PowerPoint 개별 객체로 유지한다.
- 실제 문서 이미지만 래스터 이미지로 사용한다.

## 콘텐츠

- 사고일시: 2024-08-26 07:20
- 사고장소: 충남 예산군 삽교읍
- 사고유형: 차대차
- 사고원인: 진로변경·방향지시등 미점등
- 피해내용: 부상 1명
- 개인정보: MASKED
- RAG 검색 입력: 회전교차로·차로변경·방향지시등 미점등
- RAG 검색 결과: 유사 심의사례·과실 쟁점·추가 필요 증거

## 검수 기준

- 제목과 하단 결론은 한 줄을 유지한다.
- 본문은 16pt 이상, 소제목은 24pt 이상, 슬라이드 제목은 35pt 이상으로 한다.
- Microsoft PowerPoint에서 정상 개방되고 모든 텍스트·도형이 편집 가능해야 한다.
- 최종 렌더에서 잘림, 의도하지 않은 겹침, 깨진 연결선이 없어야 한다.
