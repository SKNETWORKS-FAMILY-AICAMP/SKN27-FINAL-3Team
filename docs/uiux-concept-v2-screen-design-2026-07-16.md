## 1. v1 대비 변경점

- 화면 수 5개로 정리: `흐름도(flow)`, `홈(home)`, `AI 상담(consult)`, `사건 워크스페이스(workspace)`, `리포트(report)`
- v1에 있던 별도 `intake`(접수) 화면을 없애고, 접수 과정 전체를 `AI 상담` 단일 화면 안에서 처리
- 흐름 전체를 한눈에 보여주는 `흐름도` 화면을 새로 추가 (다른 화면으로 이동 없이 구조만 확인 가능)
- 핵심 원칙: **사용자가 사건 유형(과태료/과실비율/법령검색)을 직접 선택하는 화면·단계가 없다.** 자유 텍스트를 입력하면 백엔드(Supervisor)가 자동으로 분류한다.

---

## 2. 전체 흐름

```
[홈] → [AI 상담 (단일 채팅, 자동 분류)] ⇄ (되묻기 왕복)
                    │ "사건으로 저장"
                    ▼
            [사건 워크스페이스] ⇄ [AI 상담]  (자료 부족 시 되돌아가는 경로)
                    │ "리포트 보기"
                    ▼
                [리포트] → "내 사건에 저장" → [사건 워크스페이스]
```

- 화살표 = 사용자 행동에 의한 이동, ⇄ = 왕복 가능한 구간
- 분류(과태료/과실비율/법령검색)는 화면이 아니라 AI 상담 내부에서 일어나는 상태 변화

### 확인된 불일치 (추후 정리 필요)

흐름도 화면 텍스트에는 `리포트 → 저장 → 사건 워크스페이스`가 3단계로 그려져 있지만, 실제 리포트 화면의 버튼은 별도 저장 단계 없이 `내 사건에 저장 → 워크스페이스로 이동` 한 번의 클릭으로 처리된다. 흐름도 설명과 실제 화면 동작을 일치시킬지는 별도 결정 필요.

## 3. 화면별 구조

### 3.0 흐름도 (flow)

다른 화면과 달리 topbar 없이 흐름 설명 전용. 섹션 3개(진입~상담, 분석~사건관리, 반복 진입 경로)로 구성되고 각 섹션은 노드(화면)와 화살표, 그리고 흐름을 설명하는 노트 텍스트로 이루어진다. 하단에 범례(사각형=화면, 화살표=이동, 분류는 화면이 아니라는 설명)가 있다.

### 3.1 홈 (home)

| 영역 | 내용 |
|---|---|
| topbar | 로고, nav(홈/내 사건/AI 상담/샘플 리포트), actions(로그인, `AI 상담 시작` 버튼) |
| 헤드라인 섹션 | 헤드라인 텍스트, 서브 카피, CTA 2개(`AI 상담 시작`→consult, `샘플 리포트 보기`→report) |
| 사건 카드 미리보기 | 사건명/확인된 사실/아직 불확실/자료 충족도를 보여주는 박스 1개 |
| ~~가치 설명 (4박스)~~ | **2026-07-16 제거** — 4개 박스로 나열된 가치 설명 섹션은 불필요 판단으로 삭제 |
| 예시 프롬프트 | 클릭 시 상담 입력창에 문구가 채워지는 버튼 3개(`과태료 고지서를 받았어요` 등). **사건 유형 선택이 아님**을 노트로 명시 |

### 3.2 AI 상담 (consult)

단일 채팅 화면, 좌측 메인 패널 + 우측 사이드바 2열 구성(`consult-body` grid).

- 좌측 패널: 안내 문구 → 자동 분류 배지(`route-badge`, 미분류 시 `pending` 스타일) → 대화 내역(`convo`, user/ai 말풍선 + 분류 메타 표기) → 입력 정보 진행률 → 첨부 자료 영역 + 업로드된 파일 행 → 입력창(파일첨부/텍스트/전송) → 하단 `사건으로 저장 → 워크스페이스로 이동` 버튼
- 우측 사이드바: "이 화면에서 자동으로 일어나는 일" 설명 리스트 + "입력 정보 체크리스트"(field-list, 채워짐/비어있음 표시)
- 핵심 규칙: 유형 선택 UI 없음. 문장 키워드로 자동 라우팅되고, 분류는 대화 중 배지로 표시되며 대화가 진행되며 바뀔 수 있음.

### 3.3 사건 워크스페이스 (workspace)

- 헤더: 사건명, 사건번호·자동 분류·최근 업데이트
- 상태 요약: `status-strip` 4칸(현재 판단/제출 기한/자료 충족도/리포트 상태)
- 부분 리포트 안내 배너 (원인·영향·다음 행동 한 줄 설명)
- 본문 2열(`ws-grid`)
  - 좌측 열: `AI 검토 결과`(확인된 사실 ✓ / 불확실 ?), `법적 근거`(law-item 리스트, 출처·확인일 포함)
  - 우측 열: `지금 해야 할 일`(todo-item, 우선순위 항목 강조), `부족 자료`(missing-item + 추가 버튼), `입력 정보 확인`(field-list + `이어서 답하기 → AI 상담으로 이동` 링크로 consult 왕복)

### 3.4 리포트 (report)

- 커버: `CASE REPORT · 부분 리포트 · 자동 분류` 라벨, 제목, 메타 4칸(검토일/자료 수/근거 수/완성도)
- 본문 5섹션: 1.검토 결론 → 2.사실관계 → 3.판단 쟁점과 근거(r-issue 리스트) → 4.권장 행동(번호 리스트) → 5.한계
- 하단 액션 바: 최종 갱신 시각 표시, `PDF 다운로드` / `내 사건에 저장 → 워크스페이스로 이동`(저장 단계 없이 바로 이동, 위 불일치 참고)
