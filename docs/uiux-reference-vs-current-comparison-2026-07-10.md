## 1. 한줄 결론

현재 React UI는 기준 시안의 색상·카드 스타일과 일부 문구를 가져왔지만, 핵심 화면 구조는 **사건 처리형 서비스에서 ChatGPT형 대화 앱으로 변경**되었다. 특히 별도 진입 화면, 사건/기한 중심 사이드바, 과태료·사고 전용 결과 화면, 모바일에서의 즉시 상담 접근이 기준 시안과 크게 다르다.

현재 화면을 기준 시안에 맞추려면 스타일 보정보다 `FrontendAppShell`의 화면 구조와 라우팅을 먼저 되돌려야 한다.

## 2. 일치하는 부분

- `교통분쟁 AI`의 청록색 계열 브랜드 톤
- 로그인 없이 상담을 시작하고 저장/정밀 분석 시 Google 로그인을 연결하는 정책
- 상담, 내 사건, 과거 이력, 리포트의 기능 범위
- 빠른 질문, 자료 첨부, Supervisor/Agent 분석 상태, 리포트 저장 기능
- 카드, 태그, 상태 색상, 요약 지표 등 기본 UI 어휘

## 4. 가장 중요한 발견

### P0. 모바일에서 사이드바가 상담 진입을 막음

목표 시안은 860px 이하에서 `.sidebar { display: none; }`을 적용한다. 현재 CSS는 1000px 이하에서 사이드바를 `position: static`으로만 바꾸므로, 390px 화면에서 대화 목록·계정 영역이 먼저 한 화면 이상 노출된다. 사용자는 상담 입력까지 스크롤해야 한다.

권장: 720~860px 이하에서 사이드바를 숨기고, 상단 또는 하단에 `새 상담 / 내 사건 / 리포트` 모바일 내비게이션을 제공한다.

### P0. 전용 결과 화면이 사라짐

목표 시안은 과태료와 사고 결과를 각각 별도 화면으로 제공한다. 현재 라우트는 `entry`, `chatbot`, `mypage`, `history`, `reporting`뿐이며 과태료·사고 결과 화면이 없다. 분석 결과가 채팅 카드 또는 범용 리포트 작업대로 흡수되어 사용자가 핵심 숫자와 행동을 빠르게 찾기 어렵다.

권장: 최소한 `fine-result`, `fault-result` 두 결과 뷰를 복원하거나, 하나의 `case-result` 화면에서 사건 유형별 섹션을 렌더링한다.

### P1. 제품용 UI와 개발자 점검 UI가 섞임

현재 상담 화면에는 persona smoke, `sync / async_worker / mock`, Supervisor stage, Agent node result가 존재한다. 목표 시안에도 Supervisor 플랜은 있지만 사용자용 설명 흐름 안에 제한적으로 표현되며 실행 모드 선택은 없다.

권장: 개발용 Agent 점검은 개발 환경에서만 노출하고, 사용자 화면에는 `입력 확인 → 자료 분석 → 근거 확인 → 리포트 준비`처럼 번역된 진행 상태만 표시한다.

### P1. 목표 시안의 “다가오는 일정”이 현재 사이드바에서 사라짐

교통분쟁 서비스에서 제출기한은 재방문과 행동 전환의 핵심 정보다. 현재 사이드바는 대화 목록을 중심으로 구성되어 D-3 사건과 오늘 해야 할 일이 첫 화면에서 보이지 않는다.

권장: 대화 목록보다 `기한 임박 사건`과 `추가 자료 요청`을 우선 배치한다.

## 5. 목표 시안에 맞추는 최소 변경 순서

### 1차: 구조 복원

1. `chatbot` 기본 진입은 유지한다.
2. 비진입 화면에서도 사건/결과 이동을 일관되게 제공한다.
3. 현재 ChatGPT형 `ConversationSidebar`를 목표 시안형 프로필/화면 이동/다가오는 일정 사이드바로 교체한다.
4. 모바일에서 사이드바를 숨기고 본문을 첫 화면에 표시한다.

### 2차: 결과 화면 복원

1. 과태료 결과에 납부 금액, 제출기한, 검토 상태, 필요 자료 지표를 제공한다.
2. 사고 결과에 사고 유형, 쟁점, 제출 자료, 검토 상태 지표를 제공한다.
3. 두 결과 화면 모두 본문 분석과 다음 행동을 2열로 배치한다.
4. 리포트 저장, 초안 다운로드, 상담으로 돌아가기를 결과 화면의 명확한 CTA로 연결한다.

### 3차: 상담 흐름 정리

1. 빈 화면의 높이를 줄이고 목표 시안처럼 실제 분석 흐름이 보이는 대화 예시 또는 온보딩을 제공한다.
2. 자료 첨부를 `개발용 Agent 점검` 밖의 사용자 입력 영역으로 이동한다.
3. 실행 모드 선택과 persona smoke를 개발 전용 플래그 뒤로 숨긴다.
4. Supervisor/Agent 상태는 사용자 언어로 번역한다.
