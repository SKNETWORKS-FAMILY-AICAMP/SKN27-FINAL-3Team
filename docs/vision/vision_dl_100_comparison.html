역할 분리와 안전 계약

VideoMAE

사고유형을 결정한다. confidence가 낮으면 review를 요청한다.

YOLO

객체 class/confidence/bbox만 제공한다. 과실이나 사고유형을 정하지 않는다.

Qwen3

잠긴 유형을 변경하지 않고 보이는 근거와 불확실성만 설명한다.

Handoff

JSON 재시도·fallback 후 경로와 원시 예외문을 제거해 Supervisor에 전달한다.
