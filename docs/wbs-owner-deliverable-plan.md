작성일: 2026-06-18

최종 기준일: 2026-08-04

## 1. 문서 목적

이 문서는 최신 회의 기준으로 WBS, GitHub Issue, 담당자, 산출물, 마일스톤을 다시 정리한다.

기존 GitHub Issue에는 보험 텍스트 파이프라인이 `workzion2`에 배정된 항목, 합의금 확장 항목, 보험 RAG/Front 중심 항목이 남아 있었다. 최신 기준에서는 아래 구조를 우선한다.

- 최종 답변은 개별 Agent가 아니라 Supervisor가 각 Agent 결과 스키마를 통합해 생성한다.
- 과태료·범칙금 분석은 필주 담당이다.
- 법률 데이터 수집·전처리·DB 적재는 동혁 담당이다.
- 경위서/OCR 결과, 텍스트 ML, 과실비율 판례·유튜브 자막 사례·과실비율심의사례 데이터는 재강 담당이다.
- 차량 사고 이미지·영상 및 Vision/DL 흐름은 주희 담당이다.
- 이의신청서 생성은 요청자 담당으로 고정한다.
- 보험 약관과 합의금 확장 기능은 이번 중간 WBS의 핵심 경로에서 제외하고 후순위로 둔다.

## 7. Supervisor 기준 결과 스키마 초안

개별 Agent는 최종 자연어 답변을 확정하지 않고 아래 형태의 결과를 반환한다. 최종 답변은 Supervisor가 통합한다.

```json
{
  "agent": "fine | law | precedent | text_ml | vision | objection",
  "status": "success | partial | failed",
  "summary": "Agent가 생성한 요약",
  "structured_result": {},
  "evidence": [
    {
      "source_type": "law | precedent | caption_case | review_case | fine_rule | vision_result",
      "title": "근거 제목",
      "source_url": "원문 URL 또는 내부 문서 ID",
      "metadata": {},
      "confidence": 0.0
    }
  ],
  "next_actions": [],
  "limitations": []
}
```
