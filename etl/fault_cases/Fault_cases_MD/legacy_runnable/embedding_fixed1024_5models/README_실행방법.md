# 과거 실험 모듈: 1024차원 고정 5개 모델 임베딩

이 모듈은 초기 `track_b_5models_fixed1024`에서 수행된 5개 모델(BGE, OpenAI 등) 1024차원 임베딩 성능 비교 실험 코드를 포함합니다. 현재 운영은 Qwen3-Embedding-4B(2560차원)로 통일되었으나, 과거 모델 간의 비교 결과를 확인하거나 추가 모델 테스트 벤치마크 뼈대로 사용합니다.

## 실행 방법

- `src` 내부의 Python 스크립트들을 통해 임베딩을 생성하고 평가할 수 있습니다.
- 사전에 필요한 데이터셋(평가 질문 50건)이 준비되어야 합니다.
