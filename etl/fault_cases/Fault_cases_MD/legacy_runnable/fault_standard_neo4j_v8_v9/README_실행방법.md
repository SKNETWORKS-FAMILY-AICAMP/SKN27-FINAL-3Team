# 과거 실험 모듈: 인정기준 V8/V9 Neo4j

이 모듈은 `NEW_ABC_TEST` 및 `NEW_ABC_TEST_V6` 폴더에 있던 과거 인정기준 RAG(V8, V9)의 실험 코드를 포함합니다. 현재 `rag_runtime`으로 이관된 운영 버전과의 회귀 테스트나, 예전 실험 결과를 재현해야 할 때 사용합니다.

## 실행 방법

- `NEW_ABC_TEST` 폴더 내부의 기존 스크립트 실행 방식을 따릅니다.
- **주의**: 이 모듈은 기존 하드코딩된 절대경로나 실험용 DB 구성을 참조할 수 있습니다. 
- 환경 변수 `.env` 파일은 각 폴더 내에 맞게 재구성해야 합니다.
