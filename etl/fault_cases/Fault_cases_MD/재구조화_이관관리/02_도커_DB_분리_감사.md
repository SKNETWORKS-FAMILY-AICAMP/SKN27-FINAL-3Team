## UI 혼동 방지 설계 결정

Docker Desktop은 실행 중인 모든 컨테이너를 전역 목록으로 표시하므로, 법률 Neo4j를 특정 프로젝트 화면에서만 숨길 수 없다. 숨김을 위해 중지·삭제하는 방식은 법률 서비스를 훼손할 위험이 있어 사용하지 않는다.

신규 운영 Compose에서는 다음 이름을 사용한다.

- 법률 기존 서비스: 향후 점검 시간에만 `skn27-law-neo4j`로 명확화 검토
- 인정기준 신규 서비스: `fault-standard-neo4j`
- 판례 신규 검색 DB: `precedent-postgres`
- 심의사례 신규 검색 DB: `review-case-postgres`

컨테이너 이름 변경은 재생성이 필요한 운영 변경이므로, 1~4단계에서는 수행하지 않는다. 신규 컨테이너가 기존 법률 컨테이너의 포트(7474/7687), 볼륨, `NEO4J_AUTH`를 재사용하는 것은 금지한다.
