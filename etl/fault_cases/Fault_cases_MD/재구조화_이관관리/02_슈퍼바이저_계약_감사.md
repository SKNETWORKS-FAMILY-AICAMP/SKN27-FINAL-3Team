# 2단계 슈퍼바이저 계약 감사

## 기준 계약

기존 `src/agents/text_ml_case_search/schemas.py`의 `AgentContext`와 `AgentOutput`을 현재 외부 계약 v1의 기준으로 유지한다. 단계 3의 공통 계약은 이 구조를 대체하지 않고, 세 RAG 결과를 같은 형식으로 넣기 위한 호환 계층이다.

## 입력 핵심 필드

| 필드 | 의미 | 처리 |
|---|---|---|
| `session_id`, `message_id`, `job_id` | 추적 식별자 | 그대로 전달 |
| `node_code` | 호출 노드 식별자 | 그대로 전달 |
| `query_text` | 검색 질의 | 세 RAG의 공통 입력 |
| `raw_user_text` | 원문 문장 | 정규화·근거 보존용 |
| `vision_evidence`, `ocr_evidence` | 이미지·OCR 근거 | 선택 입력 |
| `insurer_claim` | 보험사 주장 | 인정기준 비교의 선택 입력 |
| `required_outputs` | 요청 결과 범위 | 라우터 호출 범위 결정 |

## 출력 보존 필드

`contract_version`, `node_code`, `status`, `structured_result`, `evidence`, `next_actions`, `limitations`, `missing_fields`는 변경 없이 보존한다. 최종 결론과 자연어 응답은 슈퍼바이저의 책임이며, RAG 런타임은 근거 묶음만 반환한다.

## 신규 공통 검색 근거 필드

| 필드 | 의미 | 금지 사항 |
|---|---|---|
| `source_type` | `fault_standard`·`precedent`·`review_case`·`law` | 물리 DB명 노출 금지 |
| `source_reference` | 논리 식별자 (`precedent:<case_id>#<chunk_id>` 등) | 환경별 포트·테이블명 사용 금지 |
| `rank` | 후보 순위 | 점수와 혼동 금지 |
| `similarity_score` | pgvector 코사인 유사도 | 신뢰도와 혼동 금지 |
| `retrieval_score` | 검색 결합 점수 | 코사인 점수로 오기 금지 |
| `rerank_score` | 재순위화가 있을 때만 | 없는 경우 임의 0 입력 금지 |
| `score_type` | 점수 산식 설명 | 빈 문자열 금지 |
| `confidence` | 근거 완전성·출처 품질 | 코사인 유사도 복제 금지 |
| `metadata` | 도메인별 조건 | qrels·정답 ID 유입 금지 |

## 도메인별 반환 책임

| RAG | 입력 | 반환 |
|---|---|---|
| 인정기준 | 사고 Fact JSON + 질의 | 후보 규칙·계산 결과 또는 `UNKNOWN`·근거 |
| 판례 | 사고 Fact + 검색 질의 | B-4 질의 보강 후 판례 후보·원문 근거 |
| 심의사례 | 사고 Fact + 검색 질의 | 심의사례 후보·원문 근거 |

## 계약 감사 결론

- 기존 외부 계약과 충돌하는 필드는 발견하지 않았다.
- 공통 검색 근거 필드는 `Evidence`와 `SimilarCase`에 호환 어댑터로 추가할 수 있다.
- 최종 답변 생성·과실비율의 최종 법률 판단을 새 RAG 런타임이 수행하지 않는다.
