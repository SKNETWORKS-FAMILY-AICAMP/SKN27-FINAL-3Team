## 참조 안전성 원칙

1. 3단계 신규 패키지는 기존 경로를 옮기지 않는다.
2. 신규 런타임에서 실험 코드 전체를 import하지 않는다. 필요한 함수·규칙만 작고 명시적인 어댑터로 감싼다.
3. 어댑터에는 원본 경로·함수명·입력·출력·예외 변환 규칙을 주석과 문서에 기록한다.
4. 기존 모듈의 상대 import가 깨지지 않도록 `src/` 하위의 현 위치를 유지한다.
5. HISTORY로 분류된 실험 코드는 삭제하지 않으며, 실행하려면 전용 재현 환경과 입력 snapshot을 사용한다.

## 3단계 전 확인 결과

- 기존 슈퍼바이저 계약은 TypedDict 기반이므로, 신규 계약도 외부 직렬화는 JSON 호환 구조를 유지해야 한다.
- 판례 B-4는 질문 ID나 정답 판례 ID가 아닌 사고 조건 규칙 JSON을 읽는 구조여야 한다.
- 인정기준 계산기는 결과를 산출할 수 없는 경우 명시적으로 계산 불가 상태를 반환해야 하며, 신규 계약도 이를 `UNKNOWN`으로 보존해야 한다.
