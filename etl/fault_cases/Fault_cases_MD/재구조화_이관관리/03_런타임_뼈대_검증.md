- 기존 법률 Neo4j 연결 또는 수정

## 계약 검증

다음 스모크 테스트를 통과했다.

1. 모든 신규 Python 모듈 컴파일
2. `fault_standard`, `precedent`, `review_case` 어댑터 import
3. 구현 전 상태가 빈 성공 결과가 아니라 `status: unknown`으로 반환되는지 확인
4. 논리 출처 형식 `precedent:case-1#chunk-2` 생성 확인
5. 세 도메인 결과를 결합하되 최종 판단을 하지 않는지 확인
