## Complete30 공식화 방식

원본 `NEW_ABC_TEST_V6/evaluation/v7_complete30/`는 유지했다. 그중 현재 승인한 질문지·정답지·`complete30_manifest_v1.1.json`만 `evaluation/fault_standard/complete30_v9/v1/`로 복제했다.

세 파일은 원본과 복제본의 SHA-256이 모두 일치할 때만 승인한다. 이전 `complete30_manifest.json`은 현재 공식 매니페스트로 사용하지 않는다.

## 생성물

- `evaluation/공식_평가자산_매니페스트_v1.json`
  - 공식 질문지·정답지·qrels의 상대 경로, SHA-256, 크기, JSONL 행 수를 기록한다.
- `docs/README_문서_지도.md`
  - 운영 설계·인정기준·3코퍼스 임베딩·판례 운영 결정의 활성 문서를 안내한다.

## 검증 결과

1. 모든 JSONL을 행 단위 JSON 파싱으로 검사했다.
2. 공통 질문지는 50행, Complete30 질문지·정답지는 각각 30행임을 확인했다.
3. 인정기준 v1.2 qrels는 111행, 심의사례 qrels는 89행, 판례 qrels는 58행임을 확인했다.
4. Complete30 복제본 3개 파일은 원본과 SHA-256이 일치한다.
5. 문서 지도에 등록한 활성 경로의 존재 여부를 확인했다.

## 이 단계에서 하지 않은 작업

- 기존 평가 자산 삭제·이동
- 질문지·정답지 내용 수정
- DB 적재 또는 검색 결과 재측정
- HISTORY 폴더로의 실제 대량 이관
