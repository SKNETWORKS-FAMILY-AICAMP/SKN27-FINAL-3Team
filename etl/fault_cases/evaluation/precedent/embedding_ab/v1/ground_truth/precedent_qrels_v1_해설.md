# 판례 Ground Truth q01~q50 해설집

이 문서는 `common_fault_queries_v1.jsonl`의 50개 사용자 사고 Query에 대해 `precedent_qrels_v1.jsonl`이 어떤 판례를 정답으로 지정했는지 문항별로 풀이한다.

```text
relevance 3: 핵심 사고관계와 과실 쟁점이 직접 일치
relevance 2: 핵심 구조는 같고 부차 조건 또는 추가 쟁점이 존재
relevance 1: 사고 주제만 관련되고 책임 판단을 바꾸는 핵심 조건이 다름
관련 판례 없음: 현재 판례 987건에서 relevance 1 이상 판례를 확인하지 못함
```

relevance 2 이상만 Hit와 MRR의 정답으로 사용한다. relevance 1은 nDCG에서 참고 판례로만 사용한다.

# 부록 B. 평가 계산 기준

## Case-level 검색지표

```text
Case Hit@K / Case MRR@10
  relevance 2 이상 정답이 있는 21개 Query만 계산

Case nDCG@10
  relevance 1 이상 판례가 있는 34개 Query만 계산
  gain = 2^relevance - 1
  discount = 1 / log2(rank + 1)
  unjudged document = relevance 0
  같은 case_id의 여러 청크는 검색순위가 가장 높은 하나만 유지
```

Case-level 지표가 이번 모델 비교의 주지표다. 현재 qrels의 `chunk_id`는 각 판례의 대표 증거 청크이므로 모든 관련 청크를 완전하게 라벨링한 Chunk-level 정답지는 아니다.

## Negative Query 진단

관련 판례 없음 16개를 일반 Hit/MRR/nDCG에 섞지 않는다. 대신 다음을 별도로 보고한다.

```text
strict positive: relevance 2 이상 정답 Query 21개
weak-only: relevance 1만 있는 Query 13개
negative: relevance 1 이상 판례가 없는 Query 16개

모델별 positive/negative Top-1 cosine similarity 분포
strict positive 대 negative의 AUROC 및 AUPRC
negative Query의 최대 유사도 평균·중앙값·최댓값
```

임계값 없이 검색기가 항상 Top-1을 반환하면 negative false-positive rate는 항상 100%이므로 단독 지표로 사용하지 않는다. `FP@threshold`와 abstention F1을 계산하려면 최종 test 50개와 분리된 dev set에서 모델별 임계값을 먼저 정해야 한다. weak-only 13개는 임계값 학습과 이진 AUROC에서 제외하고 별도 진단한다.

## Negative 재검수

모델 실행 후 5개 모델의 Top-10 합집합을 모델명을 가린 상태로 pooling하여 negative 16개에 누락 판례가 없는지 다시 확인한다. 이 pooling은 Ground Truth 보완 절차이며 Hybrid 검색 실험이 아니다. 누락이 발견되면 qrels 버전과 SHA를 갱신한 뒤 5개 모델을 모두 재평가한다.
