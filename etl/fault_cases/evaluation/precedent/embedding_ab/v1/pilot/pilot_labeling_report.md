# 판례 Ground Truth 파일럿 v1

## 상태와 범위

이 파일럿은 판례 검색 relevance 기준을 맞추기 위한 `draft`다. 정식 50개 Ground Truth 중 먼저 검토한 10개이며, 두 번째 검수자의 합의 전에는 `approved`로 사용하지 않는다.

```text
공통 Query: 10개
사고그룹: 10개 전체에서 각 1개
난이도: easy 4 / medium 2 / hard 4
판례 코퍼스: latest RAG-ready 987건
판례 청크: precedent_chunking_v2 8,334개
has_relevant_document: 6개
no_relevant_document: 4개
양의 judgment(relevance >= 2): 8행
전체 qrels: 12행
```

심의사례 파일럿과 동일한 Query ID 10개를 사용했지만 정답 판정은 판례 987건과 해당 청크만 보고 독립적으로 수행했다. 심의사례 qrels나 임베딩 모델 검색 결과를 판례 정답 선정 근거로 사용하지 않았다.

## Relevance 기준

```text
3 = 사고 구조, 당사자 유형, 차량 행동, 핵심 조건이 직접 일치
2 = 핵심 사고 구조는 일치하지만 중요한 수정요소 1개 이상이 다름
1 = 기본 주제나 법리만 유사하고 핵심 사고 조건은 다름
0 = 표면 키워드만 유사하거나 실제 사고 관계가 다름
```

Hit@K, Recall@K, MRR@K의 양성 정답 기준은 `relevance >= 2`로 사용한다. nDCG@K는 0~3의 등급 관련도를 사용할 수 있다. 이 파일럿에서는 0점 후보와 주제만 유사한 1점 후보를 qrels에 넣지 않고 기각 후보로 기록했다.

## 핵심 판단 메모

### q01

`110371`은 진행신호에 직진한 택시와 우측에서 정지신호를 위반해 계속 진입한 승용차의 충돌이다. 사고 관계가 직접 일치하므로 3점이다.

`67558`은 신호 준수 직진 대 신호위반 좌회전이므로 법리는 유사하지만 상대 차량 행동이 달라 기각했다.

### q11

`117988`은 소로 차량이 시간상 먼저 진입했더라도 대로 직진 차량에 대한 양보의무가 문제 된 사건이다. Query의 선진입 대 대로 우선 충돌을 직접 다루므로 3점이다.

`200812`도 같은 쟁점을 다루지만 소로 차량의 상대 진행방향 오인과 대로 차량의 상당한 과속이 추가되어 2점이다.

### q17

`136170`은 허용 유턴구역이지만 선행 승합차와 이를 추월해 함께 유턴한 후행 오토바이의 충돌이다. `152139`는 불법 유턴 대 맞은편 직진이다. 두 사건 모두 맞은편 우회전 차량이라는 핵심 상대 행동이 없어 정답에서 제외했다.

### q25

`76859`는 후행 차량의 안전거리 미확보로 정상 정지한 선행 차량을 추돌한 사건이다. 기본 추돌 구조는 맞지만 선행 급제동 주장은 증거 부족으로 배척되었으므로 2점이다.

### q30

주차장 키워드가 있는 판례는 시설관리, 차량 보관, 화재, 주차 중 물적 충돌이 대부분이다. 주차장 통로 직진 대 주차구획 출차의 사고 관계를 확인할 수 없어 `no_relevant_document`로 판정했다.

### q34

`회전교차로`와 `환상교차로` 직접 표현은 987건에 없었다. `로터리`는 지명으로만 등장했고 실제 사고 장소는 일반 교차로였으므로 기각했다.

### q38

`165581`은 고속도로 주행차로에 선행사고 차량이 정지하고 안전표지 등 조치를 하지 못한 상태에서 연쇄추돌이 발생한 사건이다. 장소와 쟁점은 맞지만 기계 고장이 아니므로 2점이다.

`205014`는 연료 고갈로 주행차로에 정차한 뒤 경고표지판 설치 전 후행 버스가 추돌한 사건이다. 고장 원인과 충돌은 직접 일치하지만 일반 고가도로이므로 2점이다.

### q43

`76572`는 자동차가 우측 후사경으로 뒤따르는 오토바이를 보고도 3차로에서 우회전해 4차로 직진 오토바이와 충돌한 사건이다. 사고 관계가 직접 일치하므로 3점이다.

### q46

`75646`은 우회전 차량이 우회전 직후 횡단보도에서 어린이 보행자와 충돌한 사건이다. 핵심 충돌 구조는 맞지만 보행자가 녹색이 아닌 횡단금지 신호에 건넜으므로 2점으로 낮췄다.

### q50

개인형 이동장치나 전동킥보드가 보도에서 차도로 진입한 사고는 확인되지 않았다. 오토바이 도로진입 판례는 당사자 유형이 다르므로 정답으로 대체하지 않았다.

## 후보 생성과 검수 방식

1. 공통 Query의 `query_text`만 후보 검색문으로 사용했다.
2. 판례 987건과 청크 8,334개에서 사고행동 키워드, 문자 n-gram 유사도, 구조화 필드를 이용해 후보 풀을 넓게 만들었다.
3. 후보 판례의 사실관계 청크와 과실 판단 청크를 함께 읽었다.
4. 표면 키워드가 같아도 당사자 유형, 진행 방향, 신호, 충돌 관계가 다르면 제외했다.
5. 모델 A/B 검색 결과는 후보 생성과 정답 확정에 사용하지 않았다.

## 2차 검수에서 합의할 항목

1. `q11`의 `117988`을 3점으로 유지할지 확인한다.
2. `q25`에서 선행 급제동이 인정되지 않은 `76859`를 2점으로 유지할지 확인한다.
3. `q38`의 도로 종류 또는 정차 원인 차이를 2점으로 허용할지 확인한다.
4. `q46`에서 보행자 신호가 반대인 `75646`을 2점으로 유지할지, 1점으로 낮출지 합의한다.
5. 합의가 끝난 뒤에만 qrels의 `adjudication_status`와 manifest의 `approved`, `reviewed_by`를 갱신한다.
