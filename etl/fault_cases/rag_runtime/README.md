# RAG 런타임

이 디렉터리는 인정기준·판례·심의사례 RAG를 에이전트에 안전하게 연결하기 위한 **신규 운영 뼈대**다. 기존 `src/`, `NEW_ABC_TEST_V6/`, 실험 산출물은 이곳으로 이동하지 않는다.

## 현재 단계

- 3단계: 공통 계약·논리 출처 형식·도메인별 어댑터 인터페이스만 생성됨
- 아직 DB 적재, pgvector 검색, Neo4j 계산, 실제 에이전트 호출은 구현하지 않음
- 실제 적재는 이후 단계에서 새 운영 DB에만 수행하며 기존 법률 Neo4j는 사용하지 않음

## 구성

| 경로 | 책임 |
|---|---|
| `contracts/` | 슈퍼바이저와 세 RAG가 공유하는 JSON 호환 계약 |
| `shared/` | 논리 출처 참조 등 공통 유틸리티 |
| `fault_standard/` | 인정기준 RAG 어댑터 뼈대 |
| `precedent/` | 판례 RAG·B-4 질의 보강 어댑터 뼈대 |
| `review_case/` | 심의사례 RAG 어댑터 뼈대 |
| `agent_runtime/` | 결과를 결합만 하는 오케스트레이터 뼈대 |
| `database/` | 후속 마이그레이션·적재·검증의 전용 위치 |
| `config/` | 비밀값 없는 환경변수 예시 |

## 안전 원칙

1. `source_reference`에는 물리 DB명·포트·비밀값을 넣지 않는다.
2. 법률 Neo4j는 신규 인정기준 RAG가 연결·수정하지 않는다.
3. 판례 B-4 보강에는 Query ID·qrels·정답 판례 ID를 넣지 않는다.
4. 이 패키지의 모든 실제 DB 연결은 별도 적재·검증 단계의 승인 뒤에만 추가한다.
