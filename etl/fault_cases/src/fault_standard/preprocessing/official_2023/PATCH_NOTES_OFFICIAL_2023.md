# official_2023 patch notes

이번 수정은 2023 자동차사고 과실비율 인정기준 전처리에서 확인된 수정 누락/하드코딩성 문제를 줄이기 위한 패치입니다.

## 핵심 수정

1. `거43-1`, `거43-2`, `거43-3` 분해 복구
   - `거43-1 제목`처럼 code와 title이 한 줄에 있는 header를 인식합니다.
   - `거43` / `-1`처럼 표 안에서 줄이 깨진 code는 rule header로 오인하지 않도록 처리했습니다.
   - 연속 child header group은 첫 child를 기준으로 묶은 뒤 개별 child rule로 확장합니다.

2. 법규/판례/활용시 참고사항 과소추출 보정
   - 페이지마다 반복되는 `목차`, 장 제목 footer/header는 제거하되, 다음 페이지에 이어지는 법규/판례 본문은 보존합니다.
   - `sanitize_evidence_block()`에서 오염 marker를 만나면 무조건 break하던 방식을 skip/break 정책으로 변경했습니다.

3. 비정상적으로 긴 rule boundary 완화
   - `MAX_REASONABLE_RULE_PAGE_SPAN` 기준을 추가했습니다.
   - `보36`, `차61-3`처럼 다음 장 본문까지 page range가 길게 번지는 경우를 완화합니다.

4. 기본과실/시나리오 보정
   - code별 본문 해설에서 `거43-1 거43-2 ... 0:100`처럼 여러 code가 같은 비율을 공유하는 문단을 파싱합니다.
   - `보22`의 도로폭별 보행자 기본과실 시나리오 `(가) 10%`, `(나) 20%`, `(다) 30%`를 `variants`로 생성합니다.
   - 시간값 `10:02`, `15:00` 등이 과실비율로 들어가지 않도록 비율 파서를 보정했습니다.

5. 수정요소 target fallback 하드코딩 완화
   - target이 원문에 없을 때 `A` 또는 `차`로 강제 fallback하지 않습니다.
   - 명확한 단서가 없으면 `None`으로 두고 parse quality flag로 검수 대상화합니다.

6. movement vocabulary 확장
   - `보도 보행`, `보도 침범 주행`, `통로주행`, `정상통행`, `합류`, `피추돌`, `후행차`, `선행차`, `적재물 낙하` 등을 추가했습니다.
