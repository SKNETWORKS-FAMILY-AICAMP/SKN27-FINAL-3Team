# Qwen 4B 세 코퍼스 RunPod 실행안내

## 목적

이 ZIP은 인정기준 277개 검색문서, 심의사례 904개 청크, 판례 8,334개 청크와 평가 질문을 `Qwen/Qwen3-Embedding-4B` 고정 리비전으로 한 번에 임베딩한다.

정답지, `.env`, `OPENAI_API_KEY`, `RUNPOD_API_KEY`, DB 비밀번호는 포함하지 않으며 실행에도 필요하지 않다.

## 실행 환경

- RunPod Jupyter
- 권장 GPU: A40 48GB 또는 RTX A6000 48GB급
- ZIP 파일을 Jupyter 파일 목록의 `/workspace`에 업로드

## 단일 실행 명령

아래 `<ZIP파일명>`과 `<실행ID>`는 전달받은 실제 값으로 바꾼다.

```bash
cd /workspace && \
mkdir -p qwen4_operational_stage6 && \
cd qwen4_operational_stage6 && \
python -m zipfile -e ../<ZIP파일명> . && \
bash etl/fault_cases/src/shared_embedding/qwen4_operational/runpod_execute_qwen4_three_corpora.sh <실행ID>
```

같은 실행 ID로 다시 명령을 실행하면 검증 완료된 shard는 건너뛰고 미완료 부분부터 재개한다.

실행기는 RunPod 기본 이미지에 남아 있을 수 있는 구형 `torchvision`·`torchaudio`·`torchtext`를 먼저 제거한다. 이 작업은 텍스트 임베딩만 사용하므로 해당 선택 패키지는 필요하지 않으며, `torch==2.7.1`과 구형 패키지가 섞여 `PreTrainedModel` import가 실패하는 것을 방지한다. 의존성 설치 직후 핵심 import와 CUDA를 검사하며, 검사 실패 시 모델 다운로드 전에 중단한다.

## 완료 확인

터미널 마지막에 다음 형식이 표시되어야 한다.

```text
완료: /workspace/qwen4_three_corpus_operational_<실행ID>.tar.gz
```

해당 tar.gz를 로컬로 다운로드해 Codex에 전달한다. 파일을 전달하기 전에 Pod를 Terminate하지 않는다. 다운로드를 확인한 뒤 먼저 Stop하고, Terminate는 결과의 로컬 검증이 끝난 후 결정한다.
