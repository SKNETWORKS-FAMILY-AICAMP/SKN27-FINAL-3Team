## 1. 개요

본 문서는 과태료·범칙금 고지서 분석 Agent의 데이터 구조, 입출력 스키마, 검증 매트릭스, 문서 유형별 필드 존재 여부를 정의한다.

---

## 2. 핵심 열거형 (Enum)

### 2-1. FineType

| 값 | 의미 | 발급 주체 예시 | 처리 |
|----|------|--------------|------|
| `"과태료"` | 행정벌 | 구청장, 시장, 경찰서장 | confidence_verification 통과 후 반환 |
| `"범칙금"` | 도로교통법 교통 위반 통고처분 | 경찰서장 | confidence_verification 통과 후 반환 |
| `"벌금"` | 형사벌 — 약식명령 | 검찰청 | ocr_status=rejected (서비스 범위 외) |
| `None` | GPT 분류 실패 | — | ocr_status=rejected (분류 즉시 단락) |

### 2-2. NoticeStage

| 값 | 의미 | 유효 FineType | 비고 |
|----|------|--------------|------|
| `"사전통지"` | 처분 전 의견 제출 기회 부여 | 과태료, 범칙금 | 과태료: 별지 154·155호의2. 범칙금: 별지 159호의2·162·163호 (OCR 전용 — 이의신청 불가, 법원행정 영역) |
| `"1차 고지서"` | 사전통지 기한 경과 후 정식 과태료 부과 | 과태료만 | 별지 151·152호. 감경 없음(100%) |
| `"즉결심판"` | 법원 출석 통지 | 범칙금만 | 별지 168호 |

> - 과태료 2차 고지서(납부독촉장)는 도로교통법 시행규칙 별지 서식으로 존재하지 않으며, 서비스 범위 외로 제외한다.
> - fine_type × notice_stage 조합이 "유효 FineType" 열에 없으면 confidence_verification에서 partial 처리. 예: 범칙금+"1차 고지서" → 무효. **(R-01)**

### 2-3. OcrStatus

| 값 | 의미 | Supervisor 액션 |
|----|------|----------------|
| `"success"` | 모든 critical + important 필드 정상 | 결과 직접 활용 |
| `"degraded"` | critical 정상 / important 일부 누락 (또는 구조적 부재 필드 허용) | 이미지 재업로드 요청 또는 허용 수준 판단 |
| `"partial"` | critical 누락 또는 형식·조합 오류 | 이미지 재업로드 요청 |
| `"failed"` | 판독 불가 / JSON 실패 / PDF 초과 / 이미지 없음 | 이미지 재업로드 요청 |
| `"rejected"` | 벌금(형사벌) 또는 고지서 인식 불가 | 서비스 범위 외 안내 |

## 3. LangGraph State 스키마

### 3-1. TypedDict 정의

```python
from typing import Optional
from typing_extensions import TypedDict, Literal

OCRStatus   = Literal["success", "degraded", "partial", "failed", "rejected"]
FineType    = Literal["과태료", "범칙금", "벌금"]
NoticeStage = Literal["사전통지", "1차 고지서", "즉결심판"]

class FineNoticeState(TypedDict, total=False):
    # ── Supervisor 공급 ──────────────────────────────────────────
    notice_image:               Optional[str]   # base64 이미지 (OCR 후 None)
    notice_mime_type:           Optional[str]   # "image/jpeg"|"image/png"|"application/pdf"

    # ── ①ocr_node 출력 ──────────────────────────────────────────
    ocr_status:                 Optional[OCRStatus]
    ocr_error:                  Optional[str]   # 구조 오류 메시지 (R-08, R-03)
    fine_type:                  Optional[FineType]
    notice_stage:               Optional[NoticeStage]
    law_code:                   Optional[str]
    violation_text:             Optional[str]   # 마스킹 후
    violation_datetime:         Optional[str]
    violation_location:         Optional[str]
    fine_amount:                Optional[int]
    prepayment_amount:          Optional[int]   # 과태료 사전통지만 유효 (R-06)
    opinion_deadline:           Optional[str]   # YYYY-MM-DD (R-04). ② = 납부기한 (이의신청 기한 ≠ 납부기한, Supervisor 별도 계산)
    payment_deadline_2nd:       Optional[str]   # YYYY-MM-DD. ③ 전용 — 2차 납부기한 (R-04)
    additional_amount:          Optional[int]   # ③ 전용 — 2차 납부 시 가산금액 (fine_amount × 1.2)
    issuing_authority:          Optional[str]
    vehicle_number:             Optional[str]   # 마스킹됨
    demerit_points_base:        Optional[int]   # 범칙금 전용
    demerit_points_accumulated: Optional[int]   # 범칙금 전용
    charge_number:              Optional[str]   # 과태료·범칙금 통고서 전용
    court_venue:                Optional[str]   # ④ 즉결심판 전용 — 출석 장소
    missing_fields:             list

    # ── ②confidence_verification 출력 ───────────────────────────
    format_errors:              list            # 형식·조합 오류 목록 (R-01)
```

### 3-2. OCR 필드 초기화 (R-03)

새 이미지가 도착하면 ocr_node가 `result.get("ocr_error")`로 ocr_error를 덮어써 이전 오류를 초기화한다. 성공 시 result에 ocr_error가 없으므로 None으로 초기화, 실패 시 오류 메시지 유지.

## 4. 문서 유형별 필드 존재 여부

### 4-1. 4종 분류 기준

| 유형 | fine_type | notice_stage | 서식 번호 | 분류 조건 |
|------|-----------|-------------|-----------|---------|
| ① 과태료 사전통지서 | 과태료 | 사전통지 | 별지 154·155호의2 | — |
| ② 과태료 고지서 | 과태료 | 1차 고지서 | 별지 151·152호 | — |
| ③ 범칙금 사전통지 | 범칙금 | 사전통지 | 별지 159호의2·162·163호 | — |
| ④ 즉결심판 출석통지서 | 범칙금 | 즉결심판 | 별지 168호 | — |

> 과태료 2차 고지서(납부독촉장)는 도로교통법 시행규칙 별지 서식으로 존재하지 않으므로 서비스 범위에서 제외한다.
> ⚠️ 별지 162·163호(범칙금 납부고지서)는 violation_text·law_code 등 위반 내용 필드가 구조상 없어 evaluate_ocr에서 partial로 처리된다. 범칙금 전체가 법원행정(즉결심판) 영역이므로 이의신청 서비스 적용 불가.

## 5. OCR 신뢰도 평가 스키마

### 5-1. critical / important 필드 정의

| fine_type | critical (누락 → partial) | important (누락 → degraded) |
|-----------|--------------------------|----------------------------|
| 과태료 | law_code, violation_text, notice_stage | fine_amount, opinion_deadline, issuing_authority, charge_number |
| 범칙금 | law_code, violation_text, notice_stage | fine_amount, opinion_deadline, vehicle_number, violation_datetime, violation_location |

> **구조적 부재 예외** — critical 필드가 서식 자체에 없는 경우 partial 대신 degraded 처리:
> - ④ 즉결심판 출석통지서 (별지 168호): law_code, vehicle_number 서식 구조상 없음

### 5-2. evaluate_ocr() 로직

```python
def evaluate_ocr(fields: dict, fine_type: str, notice_stage: Optional[str] = None) -> tuple[str, list[str]]:
    # ④ 즉결심판: law_code·vehicle_number 구조적 부재 → critical/important에서 제외
    absent    = _STRUCTURAL_ABSENT.get((fine_type, notice_stage), set())
    critical  = [f for f in CRITICAL_FIELDS[fine_type]  if f not in absent]
    important = [f for f in IMPORTANT_FIELDS[fine_type] if f not in absent]

    missing_critical  = [f for f in critical  if not fields.get(f)]
    missing_important = [f for f in important if not fields.get(f)]

    if missing_critical:
        return "partial", missing_critical + missing_important
    if missing_important:
        return "degraded", missing_important
    return "success", []
```

## 8. 검증 규칙 전체 목록

| 검증 ID | 필드 | 규칙 | 실패 처리 | 적용 노드 |
|---------|------|------|----------|---------|
| V-01 | notice_stage | {사전통지, 1차 고지서, 즉결심판} 중 하나 | ocr_status=partial | ② |
| V-02 | fine_type | {과태료, 범칙금} 중 하나 — 벌금·None은 ① ocr_node에서 이미 rejected | 해당 없음 | ① |
| V-03 | fine_amount | 양의 정수 (> 0) | ocr_status=partial | ② |
| V-04 | law_code | `.+(법\|규칙\|령\|조례\|규정).+제\d+조` 패턴 | ocr_status=partial + format_errors | ② |
| V-05 (R-01) | fine_type × notice_stage | VALID_COMBINATIONS 매트릭스 일치 | ocr_status=partial + format_errors | ② |
| V-06 (R-04) | opinion_deadline | YYYY-MM-DD 형식 파싱 가능 | 파싱 불가 → None 저장 | ① |
| V-07 (R-08) | notice_image (PDF) | len(pdf_pages) ≤ 10 | ocr_status=failed, ocr_error 기록 | ① |
